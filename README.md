# Cyberbullying Detection Using Machine Learning and Deep Learning

## Overview
This project detects cyberbullying in social media comments using a combination of Machine Learning and Deep Learning techniques. The application is built with Flask and provides real-time predictions through a simple web interface.

## Features
- Detects cyberbullying in user-entered text
- Combines Logistic Regression and LSTM for prediction
- Calculates a cyberbullying score
- Categorizes comments by severity
- Flask-based web application

## Technologies Used
- Python
- Flask
- TensorFlow
- Scikit-learn
- Pandas
- HTML
